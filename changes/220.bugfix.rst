- Bug in imagesubtraction.sky_subtract: the nonlinear detection mask was being included in the segment_img.make_source_mask() call, which is a problem because nonlinear threshold is set by default to 1000, and detection threshold is set to nsigma=20. So, when I ran the simple Gaussian tests, the entire image got excluded, which appeared as a "singular matrix error" in the SFFT subtraction step. I moved the nonlinear detection mask to be combined with the source mask after the source mask is made. I suppose this issue could also be circumvented by leaving the code as it was and tuning the values for nonlinear_threshold and/or nsigma in the config, but I predict this portion of the code will change drastically soon, anyway (see: https://github.com/Roman-Supernova-PIT/sidecar/blob/u/wmwv/agent-debugging/sidecar/subtraction.py#L177, and also Lei is working on fine-tuning SFFT.)
